# Reporting a security problem

If you find a security problem in this app (for example a way to see someone else's data, or to change something you shouldn't be able to), please e-mail **nurrenaissance@gmail.com** with what you found and how to repeat it. Please don't post it publicly first, and don't access other people's data beyond what is needed to show the problem. We will reply and fix it as soon as we can.

The same contact is published at https://www.nrnszn.com/.well-known/security.txt.

**For the owner:** the `Expires` date in `public/.well-known/security.txt` must be renewed every year (it is set to 2027-11-21).
